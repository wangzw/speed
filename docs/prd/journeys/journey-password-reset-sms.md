# 短信验证码重置口令

## 参与者

忘记口令的账户本人，持有该账户已证明手机的号码；不持有平台管理权限。

## 前置条件

- 账户已设置口令，并有一个用户名或选作登录方式的邮箱（口令登录需要登录名）。
- 账户有一条本人用验证码证明过的手机；该手机不必是登录方式。
- 部署提供匿名口令重置的短信渠道，登录面因此出现「忘记口令」入口。
- 参与者能在该手机上接收短信。
- 参与者在另一台设备上保持着一个活跃会话。

## 步骤

1. 在未登录状态下打开产品，登录面的口令渠道下出现「忘记口令」入口。
2. 点「忘记口令」进入口令重置面，选择短信，填入该账户的手机号并提交。
3. 界面给出不点名账户是否存在的提示，并出现验证码、新口令与确认口令字段。
4. 读取手机收到的验证码，填入验证码、新口令与确认口令并提交。
5. 界面确认口令已重置，并提供回到登录面的出口。
6. 用该账户的用户名，或它选作登录方式的邮箱，与新口令登录；登录成功，进入该账户的租户区。
7. 退出登录，再用旧口令登录；登录被拒，界面给出凭据无效的提示。
8. 在另一台设备上刷新页面；该设备的会话已结束，界面要求重新登录。

## 结果

- 新口令可以登录，旧口令不再可用。
- 另一台设备上重置前的会话已结束。
- 账户的联系方式与登录方式、第二因素清单没有变化；若账户登记了第二因素，下一次登录仍停在第二因素。
- 重置过程没有让参与者进入账户区。

## 备选路径

- 错误或过期的验证码：界面给出与「号码不属于任何账户」相同的拒绝提示。
- 从未关联的手机号：同样的提示，不会有短信到达；任意验证码得到同一条拒绝提示。
- 账户登记了第二因素：第 6 步登录仍停在第二因素。
