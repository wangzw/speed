# 账户自助写面归前端组件族

## 状态

已接受

## 背景

authn 后端的自助写路由已经存在：档案面（`authn.profile`）挂 `PATCH B/me`，自写显示名、通用属性集、语言与时区；登录自助面（`authn.login`）挂 `PUT B/password`、`POST B/phone`、`POST B/phone/verify`、`DELETE B/identifiers/:id`、`DELETE B/links/:id`。这些路由都要求新鲜认证，未提权时答 401 `authn.insufficient_user_authentication`。

前端 `@speed/account-ui` 交付的节覆盖偏好（语言与时区）、会话、社交绑定与两步验证，不含档案字段与口令、手机、登录标识的写。

这留下一段自助面在包外。这些写与包内各节同处一个账户页、共享同一条访问令牌与同一组 `@speed/api-sdk` 生成调用，且都经同一条提权流程（一条 `purpose: 'step-up'` 的流程）。档案面的另一半字段（语言与时区）已在包内的偏好节，档案面的显示名却在宿主；一个端点的写在包内外各占一半。

## 考虑过的选项

### 保持现状：自助写留在宿主内容

**否决**：包内已交付偏好节（同一 `PATCH B/me` 的一半字段）与社交绑定的解绑，档案字段与口令却留给宿主，一个端点的写在包内外各占一半；账户页要凑齐自助写，每个宿主重复实现同一提权门控与同一批错误文案。

### 把自助写并入偏好节

**否决**：偏好节是语言与时区两个下拉的自写，口令、手机与登录标识各自是独立的多字段表单与两步流，并入使一个节承载互不相干的四种写。

### 新增四个自助写节并接入 ui-kit 的表单家族

**否决**：四节是受控面而非登录表单——每节带一次异步读（`AsyncSection`）、一条整次尝试失败横幅（`InlineError`）与会话级成功 live region，四节里唯一的客户端校验是口令节提交期的两条便利检查（新口令非空、两次一致），其权威在服务端。把只有两条提交期检查的受控面接上 `useForm` 与 schema 驱动的 resolver 只增机械；表单家族（`FormField`、`zodFormResolver`）归同层 `@speed/auth-ui` 的登录表单。本包既有的偏好节同为受控字段。

### 在 account-ui 内新增四个自助写节

**采纳**，见决策。

## 决策

采纳：账户的自助写面归 `@speed/account-ui`，新增四节——`ProfileSection`（显示名，`PATCH B/me`）、`PasswordSection`（`PUT B/password`）、`PhoneSection`（`POST B/phone` 与 `POST B/phone/verify` 两步）、`IdentifiersSection`（读 `GET B/me` 的 `identifiers` 字段、删 `DELETE B/identifiers/:id`）。四节都取 `AuthSession` 为唯一属性，只为提权门控驱动一条 `purpose: 'step-up'` 流程。

判据是「自助面同处一页、同一会话、同一提权门控」。这些写与包内既有的偏好、会话、绑定节共享同一个账户页与同一条访问令牌，都是一次性写而非可分页列表，与包内各节处在同一组件层。通用属性集（自由键值对）的编辑留在宿主：它是任意键值，不属于账户页的固定字段。

四节建为受控字段：MUI 的 `TextField` 直接受控，不接入 ui-kit 的表单家族（`FormField`、`zodFormResolver`）——判据是被否决的表单家族方案。「本包不属表单家族」是这一决策的一部分：表单家族只服务于登录表单（`@speed/auth-ui`）。

## 后果

账户页的自助写整体由包交付，宿主只组合节并供给会话。`@speed/account-ui` 的公开面新增四个节与四个 props 类型，是对公开面的附加式扩展。

**接受的代价：**

- 包多担四条自助路由与一个通用提权门控（`src/internal/step-up-gate.ts`），测试面随之扩大。
- 通用属性集的编辑仍不在包内，账户页的档案写是不完整的一半：显示名在包内，自由属性在宿主。
- 自助写要求新鲜认证，节必须处理提权 401；宿主若自建档案写面（不经本包）要自己实现同一门控。
- 四节不接表单家族：口令节的两条提交期检查以内联助手文本渲染在各自字段上，不走 `FormField`；一个校验增长到需要 schema 驱动的新节要重新评估接入成本。

## 失效条件

- 出现一种自助写，其授权依据不是「发起者就是这个账户」或不经同一提权门控：四节的共同判据不再覆盖它，归属要重新裁定。
- 账户页不再由 account-ui 组合（宿主自建账户页）：自助写归包内的理由（同处一页）随之消失。
