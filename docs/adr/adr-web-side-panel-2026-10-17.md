# 控制台列表页的行详情与创建改由侧边面板承载，面板是页内状态而非路由

## 状态

已接受

## 背景

控制台账户页（`web/packages/console-ui/src/AccountsPage.tsx` 的 `AccountsPage`）把次级任务内联在列表所在的页面里：账户创建表单常驻于页头与筛选区之间，账户详情（只读字段，因子、服务密钥与会话各一次读，以及账户级写入）渲染在列表之后。后果可观察：

- 选中一行后，视口内只有行的高亮变化，详情落在列表与表格分页之下；页面用 `scrollIntoView` 与焦点转移补救这一点。
- 创建表单占据列表上方的固定高度，首屏的数据行被推向下方。

控制台的页型只有列表页、详情页、设置页与仪表盘；详情页是带独立路由的整页（租户详情、审计详情）。ui-kit 的容器组件只有 `ConfirmDialog`，用于需要立即决策的简短确认。页面的筛选、分页与选中态是页内状态，不在 URL 中；唯一读取 URL 的是 `tenant` 查询参数，它只在页面挂载时读一次作选择器初值，之后不再随 URL 变化。

需要一种容器，承载「比对话框占更多空间、操作者仍需参照背后列表」的次级任务，并说明它的状态落在哪里。

## 考虑过的选项

### 维持现状，详情与创建表单内联在列表页

**否决**：详情的位置由页面内容的顺序决定，它越靠后，打开动作与可见结果之间的距离越远，补救逻辑（滚动与聚焦）只是把这段距离遮住；创建表单的固定高度不随使用频率变化，每次访问列表页都占用。

### 用对话框承载详情与创建表单

**否决**：对话框的语义是需要立即决策的简短内容，`ConfirmDialog` 已是这一语义的唯一实例。账户详情含因子、服务密钥、会话的表格与账户级写入，创建表单的字段以十计，放进居中的对话框，内容区高度受视口限制、宽度受 `maxWidth` 限制，表格与两列表单都被压窄；同时让「对话框」一词承载分量不同的任务。

### 账户详情改为带独立路由的整页（`/accounts/:id`），与租户详情同形

**否决**：整页的前提是任务有独立地址、需要被链接或在新窗口打开。控制台里没有任何页面链向账户详情；账户页的详情主要是写入的操作面，而不是被浏览的文档。整页还要新增一条路由声明（权限码、`requires`），离开列表页时丢掉页内的筛选与分页状态——筛选不在 URL 中，返回后不会复原。

### 侧边面板，打开状态与所选账户同步到 URL（如 `?account=<id>`）

**否决**：页面今天只在挂载时从 URL 读一次初值，从不写 URL，也不响应 URL 变化。让面板状态以 URL 为来源，需要在控制台壳与页内导航接缝上新增「写入查询参数并使页面响应其变化」的能力，这是对路由接缝（[ADR-web-route-seam-2026-10-15](adr-web-route-seam-2026-10-15.md)）的改动，范围超出引入一个容器组件。

### 无遮罩的非模态侧边面板

**否决**：背后的列表仍可点击，面板内有未保存内容时，点击另一行是丢弃、保留还是并存没有单一答案；焦点与读屏的归属也要同时描述两处可交互区域。模态把这些收为一条：面板打开时只有面板可交互。

### 模态侧边面板，状态在页内

**采纳**，见决策。

## 决策

采纳：**由 ui-kit 提供受控的模态侧边面板组件 `SidePanel`；控制台账户页的行详情与账户创建改由它承载；面板的打开状态与所选对象是页内状态，不进路由、不进 URL。**

一个次级任务用对话框、侧边面板还是整页，由任务是否需要立即决策、是否需要独立地址、是否需要参照背后的页面判定，判据与组件契约归设计文档。

## 后果

列表的筛选、分页与滚动位置在详情与创建期间保持不变，详情的打开位置与操作者的视线一致，`scrollIntoView` 一类补救不再需要；创建表单不再占用列表上方的高度。ui-kit 得到一个可复用于其它列表页的次级任务容器。

**接受的代价：**

- **面板状态不可分享、不可刷新恢复。** 刷新页面回到面板未打开的状态；账户详情没有可发给他人的地址。
- **模态使背后的页面对辅助技术不可见。** 页级的反馈区在面板打开期间读不到，面板内发起的写入的失败与成功反馈必须渲染在面板内，页面因此要区分页级与面板内的反馈面。
- **面板关闭时其内容卸载。** 面板内的局部状态随之丢失；需要跨关闭保留的状态要由宿主持有，不能放在面板内容里。
- **面板不嵌套，同一页同时至多一个。** 面板内需要更重的流程时，该流程升为整页，不在面板内再开面板。
- **ui-kit 公共面新增一个组件，且 `@mui/material` 的 `Drawer` 同时被外壳的导航抽屉与本组件使用。** 两者的地标与可及名不同，文档与命名需持续区分。
- **面板宽度档决定其内表单的列数。** 面板内的表单按面板自身的宽度取一列或两列，换档需要重新核对其内版式。

## 失效条件

- 出现从其它页面链向某个账户详情、或需要把某个账户详情发给他人的需求：该详情改为带地址的整页。
- 多个页面都需要面板状态在刷新后恢复：重新评估路由接缝上的查询参数读写能力，面板状态改以 URL 为来源。
