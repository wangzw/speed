# 审计记录的导出由检索面的一条路由承载，判定复用检索权限

## 背景

检索面由独立模块 `audit.admin` 承载，判定经授权能力的 handler 内 API 就 `audit.read` 做出，读经审计实现子包的读面完成（[ADR-audit-admin](adr-audit-admin.md)）。检索面的设计把导出留在它之外：`audit.export` 是另一份权限，导出面是宿主自建的。

一条要求把导出的判定绑在审计检索权限上：持有检索权限的运营者可以把匹配当前筛选条件的全部审计记录导出成文件；不持该权限的调用方不得导出。另一条要求规定，文件中的记录集合等于筛选匹配的全部记录，不只当前页。

读面只有一个游标分页的读，按最新在前给出一页（[design-audit](../design/modules/audit/design-audit.md)）。一个筛选的匹配集可以远大于一页，也可以远大于一个进程愿意一次持在内存里的量。

## 考虑过的选项

### 由 `audit.export` 把守一条独立路由

采纳它意味着导出是第二份权限判定，与检索分开授予，判定顺序与平台域同检索面。

**否决**：要求把导出绑在检索权限上。一个已持有 `audit.read` 的调用方能逐页读完整个匹配集，再被一份独立权限拒于同一批行的文件之外；权限目录也多出一个用数据范围分不开的码。

### 由宿主持有导出面

采纳它意味着框架只交付检索，每个需要导出的宿主自己挂路由、自己判定、自己定格式。

**否决**：与检索面同一判据（[ADR-audit-admin](adr-audit-admin.md)）：同一面在每个宿主里重写，租户隔离、判定、正文格式与文件名各自发明。

### 一次读完整个匹配集再写出

采纳它意味着先把所有页读进内存，再写一份带 `Content-Length` 的应答。

**否决**：内存与匹配集的大小成正比；而且在最后一页读到时调用方才收到第一个字节，一份长时间没有字节的下载与一条挂起的连接分不开。

### 用 CSV

采纳它意味着每条记录写成一行逗号分隔的列。

**否决**：记录视图的 `detail` 是键值对象，CSV 要么丢掉它、要么把它压成没有列结构的一个字符串；列的顺序还成为调用方与前端要各自对齐的另一份契约。

### 按 NDJSON 逐页流式写出

采纳它意味着每条记录写成一行 JSON 对象，读一页写一页，正文在读取过程中持续写出。

**采纳**，见决策。

## 决策

采纳：**审计记录的导出是 `audit.admin` 的一条检索路由，判定复用 `audit.read`，正文按 NDJSON（[REF-ndjson](../references.md)）逐页流式写出。**

路由是 `GET /api/v1/system/audit/export`，接受列表路由的筛选参数，不接受游标与页大小——两者描述的是页，不是筛选。判定与列表路由同一顺序、同一平台域、同一权限；本模块不询问 `audit.export`。正文是 NDJSON：一条记录视图一行，`detail` 因而按它自己的结构保留。处理器按读面的游标逐页读，读一页写一页，写出的行数不受一页的大小限制。

## 后果

`audit.admin` 的判定面不新增权限、不新增域、不改判定顺序。`audit.export` 仍由授权能力携带，框架内没有模块询问它；一个需要按另一份权限判定的导出由宿主自建。

**接受的代价：**

- **导出不是一个快照。** 读面按最新在前给出一页，游标指向已经读到的那一行；导出期间新写入的行标识更大，落在游标之前，不进文件；导出期间被删除的行从文件里缺席。文件是「导出期间从起点读到的那批行」，不是某一时刻的审计表。
- **正文开始写出之后不能改状态。** 第一个字节写出之后，某一页的读失败无法答成 503：连接被放弃，调用方拿到一次未完成的下载。判定、形状检查与第一页的读都在写出之前完成，它们的失败因而仍写成状态码。
- **一份权限同时管住逐页读与整集导出。** 能翻页的调用方就能把整个匹配集取下来；不想要后者时只能不给前者，框架不提供两者分开授予的形状。
- **导出的正文进了契约。** 媒体类型、一行的结构、文件名与随附响应头都是生成的契约的一部分，改动它们是宿主可见的破坏性变更。

## 失效条件

- 若出现一条要求，规定导出必须由一份与检索分开的权限判定，则本决策复用 `audit.read` 的判据不再成立。
- 若出现一条要求，规定导出文件必须是某一时刻的审计表快照，则按游标逐页读的判据不再成立。
