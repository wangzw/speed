# 键表经 Store.Declared 只读列出，敏感项不带默认值

## 背景

键表在装配期由全部声明聚合而成，每个键带着声明类型、默认值、说明文本与敏感标记（[ADR-settings-declaration](adr-settings-declaration.md)）。读写面只按单个键用到它：`Get` 要求目标的元素类型恰为声明类型，`Set` 按声明类型编码，`List` 交出已写入的行。

宿主写一个设置的管理面，要列出可设项、按类型渲染输入、显示默认值与说明、遮蔽敏感项，需要的是整张键表，而读写面交不出它：

- 别的模块声明了哪些键、各是什么类型与默认值，宿主只能照抄那份声明。抄错的类型要等写入或读取时以 `ErrTypeMismatch` 暴露，抄错的默认值则没有任何一处报出来。
- `Item.Description` 进了键表就再没有读者。
- `Sensitive` 只作用于事件载荷，`List` 与 `Get` 照常交出敏感项的值；宿主要遮蔽它们，先得知道哪些键敏感，这同样只能照抄声明。
- `Get` 的目标必须恰为声明类型，不知道类型的管理面构造不出一个合法的目标。

## 考虑过的选项

### 列为非职责，由宿主复述声明

**否决**：代价落在每个宿主身上，而且错配是静默的——默认值抄错不报错，敏感标记漏抄就把凭据交进了管理面的响应。声明式的用意是键、类型与默认值只在声明处写一次（[ADR-settings-declaration](adr-settings-declaration.md)），让宿主再写一遍，等于把它交还给调用点。

### 另立一个只读功能标识交付键表

由本模块再交付一个标识，例如 `(*Declarations)(nil)`。它的好处是 `Store` 的方法集不变，已有的替身实现不受影响。

**否决**：键表的读面与读写面没有各自的演进节奏，也没有哪个消费者只取其一——管理面列出键之后就要读写它们。这与 [ADR-settings-scope](adr-settings-scope.md) 否决"读面与写面各成一个交付"的判据相同；多一个标识，就多一次取用，也多出"取到了一个、没取到另一个"这种装配形态。

### 包级函数从注册表重建键表

`settings.Declared(reg)` 从 `core.Resources[Schema](reg)` 再聚合一次。

**否决**：这是第二处建立键表的代码，冲突与声明缺陷要在第二处再报一次；建表发生在生命周期之外，与"键表在 `New` 建立"成了两个时点；管理面手里拿的是 `Store`，不是注册表。

### 默认值以类型化的值交出

**否决**：列表的去处是客户端，类型化的值一经序列化就换了写法——`time.Duration` 按 JSON 编码是纳秒整数。`List` 交出的是行的文本，`Set` 收得下文本；默认值取声明类型自己的文本，与行是同一种写法，管理面由 `List` 的行和默认值按回落推出一个键的有效值时，不必做任何转换。

### 类型以名字或本模块自定的枚举表达

**否决**：`Get` 要求目标恰为声明类型，名字构造不出目标；自定的枚举还要另起一套类型分类，并与类型集合同步维护。`reflect.Type` 就是声明类型本身，`reflect.New(Type)` 即 `Get` 接受的目标，名字由它的 `String()` 给出。

### 敏感项的默认值随标记一起交出，由宿主遮蔽

**否决**：列表要交给客户端，一个要求每个宿主各自过滤的字段，迟早会在某个宿主那里漏出去。判据与事件载荷遮蔽敏感值相同：凭据不因为被声明，就获得传播到那里的资格（[ADR-settings-audit](adr-settings-audit.md)）。

### `Store` 增加只读方法 `Declared`

**采纳**，见决策。

## 决策

采纳：`Store` 增加 `Declared() []DeclaredItem`，按键的字节序列出键表中的全部设置项——键、声明方模块、声明类型（`reflect.Type`）、以声明类型自己的文本形式写出的默认值，以及声明给出的说明与敏感标记。它只读键表：不收上下文，不发起 IO，快照装载之前即可用，返回值归调用方。敏感项的默认值为空，敏感标记同时说明它被扣下。

`Get` 与 `List` 对敏感项的行为不变，照常交出值；管理面以列表里的敏感标记遮蔽它们。

## 后果

管理面只凭 `Declared` 就能列出全部可设项，按列出的类型构造 `Get` 的目标，把列出的默认值以文本原样交还 `Set`，不必复述别的模块的声明。`List` 里有、列表里没有的键，是声明已被删除后留下的旧行，管理面据此找出 `Delete` 要清的行。

**接受的代价：**

- **`Store` 的方法集变了。** 本模块之外实现 `Store` 的替身要补上这个方法，这是一次对外签名的变更。
- **敏感项的默认值对管理面不可见。** 要显示或比较它，只能经 `Get` 读取，那一次读到的值由宿主自己遮蔽。
- **`reflect.Type` 进入契约面。** 把它映射成客户端认得的类型描述是宿主的事，本模块不代为给出。

## 失效条件

若设置项的集合变成运行期数据（[ADR-settings-declaration](adr-settings-declaration.md) 的失效条件），键表不再在装配期定死，列表"建成后不变、不收上下文"的形态需要重新比较。
