# 冒充期间由应用壳持久显示横幅并提供结束入口，身份变更按会话边界处理缓存

## 状态

已接受

## 背景

冒充开始后，会话的主体是被冒充账户，冒充身份只到得了封闭的几条路由（见 ADR-authn-impersonation-2026-10-10）：读会话、读本人、读与结束冒充、登出，以及登记为可冒充的少数读。平台管理面的路由全部被网关拒绝。

在这个前提下，验收时在浏览器里走通全链路，发现冒充者被困在死路里：

- **结束入口只在控制台的冒充页。** 一旦离开那个已渲染的页面，再访问任何 `/console/*` 路径，都因平台权限集不满足被重定向回首页，首页、账户页、对象页、通知页能开，却没有任何冒充提示，也没有结束入口。用户菜单只有个人资料、账户设置与退出登录。唯一的界面出口是退出登录，会话整个丢掉。
- **冒充期间没有全局提示。** 唯一的可见变化是头像缩写换成了被冒充账户的。
- **控制台的重定向静默无解释。** 冒充者分不清是没有权限还是出了错。

另外两件事使问题不止是缺一个按钮：冒充开始与结束都改变此后每个读所属的身份，而查询缓存里的每一行都是在另一个身份下取的；会话快照又不携带「当前在冒充」，auth-core 自己不得知这两个事件。

## 考虑过的选项

### 保持现状，只在冒充页内放结束入口

**否决**：冒充身份到不了控制台，冒充页自己在冒充期间不可再进入；入口随页面一起消失，这正是观察到的死路。

### 在用户菜单里加一条「结束冒充」

**否决**：菜单条目没有持续的可见提示，冒充中的人仍不知道自己处于冒充；要结束得先想到去菜单里找。它解决出口，不解决「我现在是谁」。

### 控制台把被重定向到首页的请求标注原因

**否决**：设计要求非员工看不出控制台有哪些页面，对平台权限集为空者的重定向必须静默，重定向处不知道访问者是不是冒充中的员工；一旦加说明，非员工就能据此得知控制台存在。冒充者需要的解释应由与重定向无关的、只在冒充期间出现的东西给出。

### 让冒充期间的控制台继续可用

**否决**：冒充身份的平台管理面请求全部被网关拒绝，与被冒充账户持有什么权限无关；让页面照常渲染，读全部落到 401，界面会把它们读成「会话已结束」或「暂无数据」，比重定向更糟。

### 由控制台的页面库自带横幅

**否决**：控制台页面库只在控制台区渲染，而冒充期间控制台区不可达；横幅要在租户区的每个页面可见，只能属于应用壳。

### 应用壳在冒充期间持久显示横幅，结束入口在横幅里

**采纳**，见决策。

## 决策

采纳：**冒充期间，租户框架在应用栏之上的 `banner` 槽里持久显示冒充横幅，说明正在以谁的身份操作，并提供不依赖任何页面的「结束冒充」；控制台区在冒充期间一律静默重定向到租户区首页；开始与结束冒充都是一次身份变更，宿主整体逐出查询缓存并重读会话。**

- 布局包提供 `banner` 槽，装配壳透传；槽属于壳自身，路由切换时不卸载。
- 登录组件族提供展示组件 `ImpersonationBanner`，由属性驱动、不发请求、不读会话；宿主始终挂载它，没有冒充时只留空的 live region，使开始的确认可闻、刚结束的确认留得住。
- 会话快照新增 `impersonating`，只由 `restore()` 写入；快照不携带发起者的标识，看着屏幕的就是发起者。
- 横幅的内容取自快照与冒充状态读；状态读只在 `impersonating` 为真时发出，读不到租户与到期时横幅与结束控件照常。
- 开始与结束冒充落定后，宿主统一做一个身份变更动作：整体逐出查询缓存、重读会话、把宿主附上的权限集置回未知后重读，开始时再把页面带到租户区首页；控制台冒充页经一个宿主回调接入同一动作；横幅给出到期时刻时，到期那一刻宿主同样重读。
- 冒充页内的记录面收起仍保留，作为页面库自己的行为：它不依赖宿主装配。
- 各条款的细节由 layout-kit、product-shell、auth-core、auth-ui、console-ui 与示范宿主的设计文档给出，本记录不重述。

## 后果

冒充者在租户区的任何页面都看得到自己正处于冒充，随时能结束，不必靠停留在某个页面、也不必退出整个会话；冒充期间的缓存不会把一个身份下的行当成另一个身份的数据展示。控制台对非员工保持不可见，重定向仍静默。

**接受的代价：**

- **改动面跨越多个包。** 布局包、装配壳、会话核心、登录组件族、控制台页面库与示范宿主各有一处新增；都是纯附加，未使用冒充的宿主不受影响。
- **冒充期间控制台整个不可用。** 冒充者想看控制台就得先结束冒充；这是冒充身份只到得了封闭几条路由的直接结果，不是本决定带来的新限制。
- **横幅的租户只能显示标识。** 租户名册属平台管理面，冒充期间读不到，横幅的租户一项是标识本身，不是可读名。
- **冒充页的记录面收起在示范宿主里几乎看不到。** 宿主重读会话后会把页面带离控制台，收起只在宿主不做这些的装配或重读尚未落定的短暂窗口里出现；保留它是为了页面库不依赖宿主装配。
- **结束冒充成功的文案留在顶部区域里。** 横幅卸载后文案仍在那个挂载着的区域内，结果不自动消失，直到下一次尝试或页面重载替换它。
- **身份变更时整体逐出缓存会让当前页的读全部重取。** 与会话结束的缺省策略同一代价，换来不把旧身份的行带进新身份。
