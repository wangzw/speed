# 捕获面由语句、事件、请求与记录接缝构成

## 状态

已接受

## 背景

横切能力取得领域事实的途径此前只有一条：数据库模块的插件扩展点，它作用于每一条语句。那条途径覆盖数据库写操作，覆盖不到未产生写操作的领域事实，也覆盖不到写操作与业务动作之间的对应（[ADR-event-scope-2026-09-21](adr-event-scope-2026-09-21.md)）。事件总线补上业务动作与写操作之间的对应，但它按类型名发布与订阅，发布方改一个字段名即静默断开，且发布方可以选择不发布。

还有一类事实两条途径都够不到：请求本身。「谁访问了什么、结果如何」不产生写语句，也不一定产生事件。

审计的记录要写进本模块自己的表，而写表是一次语句级的写操作。写这条语句的正是捕获语句的那条通路，递归因而在形状上就存在。

## 考虑过的选项

### 只有数据库插件

**否决**：覆盖不到无写操作的领域事实与业务动作之间的对应，这条已在 [ADR-event-scope-2026-09-21](adr-event-scope-2026-09-21.md) 的背景里论证过。

### 数据库插件加事件订阅

**否决**：请求级事实两条都拿不到。免认证路由这类事实既不写库也不一定发事件，而它正是认证模块留在非保证里的那一半。

### 由入口模块直接投递请求级事实

**否决**：那要求入口模块认识审计，与入口模块「不认识任何能力、不解释任何一层」的边界冲突。

### 再加对外可调用的记录接缝

**采纳**，见决策。

## 决策

采纳：**捕获面由各条通路构成**，它们互补而非替代。

- **语句级。** 本模块声明一条 `db.Plugin` 资源，捕获钩子以具名锚点注册在写语句所在的处理器上，取的是最终语句与其结果。租户过滤插件注册在同一批处理器上、位置在这些步骤之前；本模块的锚点落在**提交那一步之前**——挂在语句自己的那一步之后不够，GORM 的排序会把那样的回调追加到链尾，落在提交之后。两侧的位置都由锚点定下，与安装次序无关；注册到同一处理器的多个插件在没有依赖声明时本无次序保证，本模块因此不声明对名册功能的构造期依赖。**捕获到的行写在那条语句自己的会话上**，不另开连接：记录与它所记录的那次写入同生共死，而一个只允许单写者的引擎没有第二条连接可争。数据库模块经 `Open` 建出的额外连接是例外，那里的语句所在的库通常没有审计表，其行的去向见 [ADR-audit-failure-2026-09-21](adr-audit-failure-2026-09-21.md)。
- **事件级。** 本模块在 `Init` 中订阅配置点名的类型。
- **请求级。** 本模块在每个受审计监听端登记一层中间件，写请求事实。
- **接缝级。** 别的模块调用本模块交付的记录接缝交出审计行。

**语句级捕获跳过写向审计表自身的语句。** 判据是比较语句的目标表与 [ADR-audit-sink-2026-09-21](adr-audit-sink-2026-09-21.md) 定下的表名常量，相等即跳过。判据成立的前提是本模块自己写审计表时走的是会设置目标表的路径。不跳过则写一条审计行会再产生一条审计行，递归不收敛。

## 后果

各条通路互不依赖，一条缺席不影响其余。

**接受的代价：**

- **覆盖面不重叠，也不互相保证。** 缺哪一条取决于装配与配置，而审计面看不出「本可以记而没记」（见 [ADR-audit-guarantees-2026-09-21](adr-audit-guarantees-2026-09-21.md)）。
- **原生 SQL 的写语句不在捕获范围内。** 只捕获经模型发出的写操作，迁移语句、宿主自己的清理与脚本都不产生审计行，而它们与「那件事没有被采集到」在审计面上同形。
- **自指判断依赖写入语句解析出来的表名与常量相等。** 改表名要与插件的判据一起改；写入语句用一个带前缀或别名的表名时两者分家，跳过失效，那条写入自己又产生一条审计行，递归就在这里发生，而它一次就会栈溢出，不会有第二次可观察的机会。
- **一个模块在本模块的受理窗口之前发出的写语句仍会被记下。** 语句级的开关是插件装没装，它在数据库模块的构造期就装好了，因而其余模块在 `Init` 里发出的模型写操作也进审计表，而请求级、事件级与接缝级三条要等 `Start`。
- **语句级这条通路的失败是抛上去的，不是报出去的。** 记录与写入在同一件工作里，所以写审计表失败会令那条业务语句失败；这是全模块唯一一处如此的通路，代价与理由见 [ADR-audit-failure-2026-09-21](adr-audit-failure-2026-09-21.md)。
- **语句级看不到意图。** 它记的是语句，不是业务动作；一次业务动作产生多条语句时，审计行的条数是语句的条数，不是动作的条数。
- **请求级与接缝级会重复。** 一个模块既在被审计的监听端上发请求、又在处理器里调用记录接缝时，同一件事留下两行，两行之间没有关联标识。

## 失效条件

若出现一类领域事实既不自语句产生、也不经总线发布、又不在请求路径上，则现有各条通路都够不到它，捕获面的划分要重新裁定。
